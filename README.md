## ✨ **Why WebTools Utility?**

Stop uploading sensitive files to random servers. WebTools Utility brings **desktop-grade file management** capabilities directly to your browser using modern web standards.

| Feature | Description |
| :--- | :--- |
| 📂 **Universal Viewer** | Native support for **Code** (JS, TS, Python), **Media** (MP4, MP3, WebP), **Archives** (ZIP, JAR), and data formats (JSON, XML). |
| ✏️ **Smart Editor** | Built-in text editor with **syntax highlighting**, regex search/replace, and snippet templates. |
| 📡 **P2P QuickShare** | Transfer files between tabs or local devices securely using **peer-to-peer channels**. |
| 🔍 **Deep Inspector** | Generate **SHA-256 checksums**, analyze binary headers, and view detailed metadata statistics. |
| 🔒 **Privacy-First** | All processing happens locally via **IndexedDB** and **Web Workers**. Your data *never* leaves your machine. |

**No installation required.** Simply open the app in any modern browser:

### **How it works**

1.  **Drop Files:** Drag and drop any file into the workspace.
2.  **Analyze & Edit:** Use the sidebar to navigate files and toggle between *Edit / Raw / Preview* modes.
3.  **Inspect:** Check metadata, hashes, and internal structure instantly.
4.  **Share:** Use **QuickShare** to send files to another tab or device without cloud storage.

---

## 🏗️ **Technology Stack**

Built with lightweight, modern web standards for **maximum performance** and compatibility:

-   **Core:** `HTML5` / `CSS3` / `Vanilla JavaScript` *(Zero framework overhead)*
-   **Archive Management:** **[JSZip](https://stuk.github.io/jszip/)** – Client-side ZIP/JAR manipulation
-   **Storage:** `IndexedDB` – High-capacity local persistence for large files
-   **Networking:** `WebRTC` / `BroadcastChannel` – Serverless P2P file transfer
