> **⚠️ Zero uploads. Zero tracking. 100% Client-Side.**
> WebTools Utility is a powerful browser-based suite for viewing, analyzing, converting, and sharing files **without ever leaving your device**.

---

## ✨ **Why WebTools Utility?**

Stop uploading sensitive files to random servers. WebTools Utility brings **desktop-grade file management** capabilities directly to your browser using cutting-edge WebAssembly and P2P technologies.

| Feature | Description |
| :--- | :--- |
| 📂 **Universal Viewer** | Native support for **Code** (JS, TS, Python), **Media** (MP4, MP3, WebP), **Archives** (ZIP, JAR), and specialized formats (NBT, JSON, XML). |
| 🔄 **Local Converter** | Convert images, audio, and video instantly via **FFmpeg.wasm**. *No server queues, no file size limits.* |
| ✏️ **Smart Editor** | Built-in text editor with **syntax highlighting**, regex search/replace, and snippet templates. |
| 📡 **P2P QuickShare** | Transfer files between tabs or local devices securely using **peer-to-peer channels**. |
| 🔍 **Deep Inspector** | Generate **SHA-256 checksums**, analyze binary headers, and view detailed metadata statistics. |
| 🔒 **Privacy-First** | All processing happens locally via **IndexedDB** and **Web Workers**. Your data *never* leaves your machine. |

## 🚀 **Getting Started**

**No installation required.** Simply visit the live application:

### 👉 [**Launch WebTools Utility Now**](https://ivan155off.github.io/WebTools-Utility/)

### **How it works**

1.  **Drop Files:** Drag and drop any file into the workspace.
2.  **Analyze & Edit:** Use the sidebar to navigate files and the top bar to toggle between *Edit / Raw / Preview* modes.
3.  **Convert:** Click **"Convert"** to transform media formats locally in real-time.
4.  **Share:** Use **QuickShare** to send files to another tab or device without cloud storage.

## 🏗️ **Technology Stack**

Built with modern web standards for **maximum performance** and compatibility:

-   **Core:** `HTML5` / `CSS3` / `Vanilla JavaScript` *(Zero framework overhead)*
-   **Media Processing:** **[FFmpeg.wasm](https://ffmpegwasm.netlify.app/)** – High-performance local transcoding
-   **Archive Management:** **[JSZip](https://stuk.github.io/jszip/)** – Client-side ZIP/JAR manipulation
-   **Storage:** `IndexedDB` – High-capacity local persistence for large files
-   **Networking:** `WebRTC` / `BroadcastChannel` – Serverless P2P file transfer
